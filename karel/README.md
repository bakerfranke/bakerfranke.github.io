# Karel (docs mirror)

This folder is **not** the Karel library source code. There are no `.py` files here.

It exists to host documentation and other resources (command references, robot images, etc.) related to the Karel robot library used in **CS 111 at UIC**, without giving students direct access to the library's source repository.

- [`docs/`](docs/) — command references and other written documentation
- [`robot_images/`](robot_images/) — the robot costume images used by the library

If you're looking for the actual library code, that lives in a separate, private repository.
