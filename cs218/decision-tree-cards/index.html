Decision Tree Card Sorting

An unplugged activity for understanding how decision trees work

In this activity, students physically sort a deck of data cards to build a decision tree by hand — no computer required. Each card represents a real-world data point with numeric features and a binary label. Students take turns finding split points, dividing the deck, and repeating until every group is "pure."

Working through the algorithm with physical cards builds intuition for how a machine learns: what it means to find a good feature, why a split might not be perfect, and how a tree grows. After the activity, the same dataset can be loaded into the Colab notebook to compare the hand-built tree against what the algorithm produces.

~45 min Groups of 3–4 No coding required Binary classification Pairs with Colab notebook

How to Run the Activity

  1. Print the activity sheet and instructions. Each sheet includes 10 data cards and blank split-point cards.
  2. Cut out the cards and distribute one set of 10 data cards per group.
  3. Students follow the algorithm on the instruction sheet — picking a feature, finding a split point, and dividing the cards — repeating until all groups are pure.
  4. Groups share their trees, discuss differences, then run the same data through the Colab notebook to see what the algorithm finds.

Customize the Data

The activity ships with a Chicago neighborhood dataset, but you can use any CSV. The Card Generator tool lets you upload your own dataset, choose features and a label column, sample 10 representative rows, and print a ready-to-use activity sheet. See the resources below for the source data and additional datasets.
