# Markov Chain Lab

A classroom tool for showing how a classic Markov chain generates text.
It runs entirely in the browser: the Python in `markov.py` and `engine.py`
runs through [Pyodide](https://pyodide.org/).

The texts here are in the public domain. Visitors can upload their own files,
which stay in their browser.

These files are generated by `publish_web.py` in the local project. Edit them
there, not here.
